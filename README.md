# Құран оқу мектебі · Школа чтения Корана

Онлайн-курс чтения Корана с нуля: 110 уроков, 23 суры с голосами чтецов, тренажёры. Казахский и русский интерфейс.

Сайт: https://maxandmum.github.io/quran/

- `index.html`, `assets/app.js`, `assets/app.css` — сайт (без сборки и зависимостей)
- `assets/data/` — уроки и тексты сур (JSON)

Текст Корана — усманский рисм, риваят Хафс. Аудио — EveryAyah и Quran.com.
